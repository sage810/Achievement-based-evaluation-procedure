# 수행평가 문항 개발 (성취기준 → 정보표 → 주제 선택 → 문항·채점기준표·예시답안)

사용법·활용법은 `docs/스킬-문항개발-사용법.md`. 이 파일은 Claude 가 따르는 절차다.
모든 생성 규칙의 기준은 `docs/문항-초안-절차.md`(칸 채우기 규칙, 발문·자료·조건 규칙, 수행 수준 쓰는 법)이며, 근거 자료는 `docs/논술형 평가/정리/00-색인.md` 부터 읽는다.

## 0. 준비
- 개발 서버가 켜져 있어야 한다(`npm run dev`, API http://localhost:8000). 꺼져 있으면 백그라운드로 켠다.
- 인자: 성취기준 코드(예: `9정04-01`, `[12정02-01]`). 「09정」처럼 0이 붙어 오면 `9정`으로 읽는다. 학교급은 코드로 정한다(`9정` = 중학교, `12정` = 고등학교).

## 1. 과제 정보표 찾기
1. `py -3.12 tools/item_draft.py find <코드>` — 과제 id 확인.
2. 없으면 `py -3.12 tools/item_draft.py new <학교급> <코드>` — 화면의 「Claude Code 초안 요청」과 같이 교육과정 분석 탭 내용(해설·고려 사항·내용 요소·평가 요소 ⑦·수준화 ⑧)으로 정보표를 미리 채워 만든다. 선생님께 「정보표가 없어 교육과정 분석으로 새로 만들었다」고 알린다.
3. `py -3.12 tools/item_draft.py show <id>` → `data/items/<id>.json` 을 읽는다. 평가 요소·문항 정보·평가 방법·이미 채워진 칸은 **그대로 살린다**(선생님이 바꾸라고 하지 않는 한).
4. 교육과정 분석(`GET /api/analyses/<standard_id>`)의 ⑥ 수준 구분 단서와 ⑦ 평가요소를 함께 읽는다.

## 2. 주제 후보를 제시하고 고르게 하기 (반드시 묻는다)
- `AskUserQuestion` 으로 주제 3~4개를 제시한다. 첫 항목은 추천안 「(추천)」.
- 후보마다 설명에 **자료로 무엇을 보여 주고 각 문항이 그 자료로 무엇을 하게 되는지** 한두 줄(예: 「게임 기능 카드 6장: 학습형 상대 캐릭터·학습형 채팅 필터(AI) vs 금지어 필터·레벨업(AI 아님) → 구별·차이점 설명」).
- 주제는 게임·인스타·유튜브·아이돌·연애·실생활 등 학생 관심사에서 고르되, **성취기준의 핵심 수행이 자연스럽게 드러나는 것만** 낸다. 억지 연결(개념과 무관한 장식)은 후보에서 뺀다. 연애는 개인정보·관계 갈등 등 정서적 부담이 없는 장면만.
- 정보표에 이미 평가 방법이 정해져 있으면 그 방법에 맞는 주제로. 문항 형식(논술형/실습형)이 바뀌어야 하면 함께 묻는다.

## 3. 문항·채점기준표·예시답안 쓰기
`docs/문항-초안-절차.md` 를 그대로 따른다. 특히:
- **발문·자료·조건**(「발문과 반응지시어 정리.xlsx」): 문두에 「무엇을 어떻게」 + 측정 능력에 맞는 반응 지시어(정보교과 정의) + [배점]. 평가 요소 1개 = 하위 문항 1개. 조건은 범위·인정 기준을 밝히되 정답·핵심어를 암시하지 않는다. 자료는 문항에 필요한 만큼만, 가상 자료면 `[출처: 수업용 가상 자료 …]`. 특정 회사·상표·실존 인물은 피하고 가상 이름을 쓴다.
- 첫 줄: `※ 다음 … 물음에 답하시오. [총 n점]`, 하위 문항: `1. … <조건>에 맞게 ~하시오. [n점]` + `<조건>` `∙ ~할 것.` 쉬운 문항 → 어려운 문항.
- **채점기준표**(「채점기준 예시.xlsx」 방식): 채점 요소마다 A·B·C·D·E 5행, 5행이 같은 뼈대, 수식어 사다리(정확하게·논리적으로 → 보통 → 부분적으로·일부)와 개수(모두 → 하나)로만 구분, 한두 문장, 「~한 경우」로 끝, 「, 또는」 나열·결핍어(못·미흡·부족) 금지. 등간격 정수 배점(E ≥ 2, 예: 6-5-4-3-2). 정답이 정해진 값은 A행 괄호나 비고에 밝힌다. 발문의 반응 지시어와 조건이 행에 그대로 반영되어야 한다.
- **기본점수 표**(`basic_score`, 「항목: 내용」 줄): 기본점수(만점의 20% 이상 40% 미만, E 최저점 합보다 낮게) / 장기 미인정 결석자(기본점수 − 1) / 산정 근거 / 참고 분할점수(각 수준 최저점 합) / 비고 ※ 3줄(만점 = 최고점 합, 40% 미만 생략, A행부터 차례로).
- **예시답안**: 문항마다 조건을 모두 갖춘 A 수준 답안을 학생이 쓸 문장으로. 자료의 수치·계산은 직접 다시 계산하거나 코드는 실행해서 맞춘다.
- 정보표의 빈칸도 함께 채운다: 과제명(「~하기」), 최소 능력자 수행 특성 A~E(「~할 수 있다.」, 채점 행과 같은 개수·조건), 수업 단계(진단→형성→수행, `[진단평가]`·`[형성평가]`·`- 교사 피드백:`·`- 동료 피드백:`·`- 최소 성취수준 보장 연계 피드백:`), 개발 방향(문항별 고려 성취수준), 채점 요소 이름.

## 4. 검사하고 넣기
1. 채운 JSON 을 `data/items/<id>.json` 에 쓴다(Python 스크립트는 스크래치패드에 Write 로 만들고 실행 — 셸 heredoc 은 따옴표·`\n` 이 깨지기 쉽다).
2. `py -3.12 tools/item_draft.py check data/items/<id>.json` — 「통과」가 나올 때까지 고친다.
3. `py -3.12 tools/item_draft.py save <id> data/items/<id>.json` — 앱에 넣는다(「AI 초안」 표시).
4. 가능하면 화면을 헤드리스 Edge 로 찍어 문항·채점기준표가 보이는지 확인한다(못 하면 「확인 못 함」).

## 5. 알리기
선생님께 한국어로: 고른 주제, 문항 구성(문항별 반응 지시어·배점), 채점기준의 수준 구분 방식, 함께 채운 정보표 칸, 선생님이 확인할 부분(가상 자료의 수치, 정답 인정 범위). 끝에 `PushNotification`.
