# 스킬·에이전트 지도

처음 만든 문서라 2026-11 UI 개선에서 쓴 것만 적었다.

## 사용 중

| 이름 | 어디에 |
|---|---|
| `impeccable` (전역 설치) | UI 비평·감사, 배치·다듬기 절차, 저장 뒤 디자인 검사 훅 |
| `better-interface` 외 `better-*` | UI 검수 |
| `project-housekeeping` | 커밋 전 마무리 |
| `superpowers:brainstorming`·`writing-plans`·`executing-plans`·`test-driven-development` | 평가계획서 탭 개편의 설계·구현 절차 |

## 추천받았지만 쓰지 않은 것

| 이름 | 쓰지 않은 이유 |
|---|---|
| `superpowers:using-git-worktrees`, `finishing-a-development-branch` | 이 프로젝트는 main에서 개발 서버로 바로 확인하고, 사용자가 요청할 때 커밋함 |
