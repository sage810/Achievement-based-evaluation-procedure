# 스킬 「assessment-item」 — 수행평가 문항·채점기준표·예시답안 만들기

성취기준 하나를 주면, 「문항 개발」 탭의 **수행평가 과제 정보표**를 보고 학생 관심 주제로 **수행평가 문항·채점기준표·예시답안**을 만들어 앱에 넣어 주는 Claude Code 스킬이다.
스킬 파일: `.claude/skills/assessment-item/SKILL.md` (이 프로젝트에서만 동작).

## 1. 사용법

Claude Code 에 다음처럼 말한다.

```
/assessment-item 9정04-01
```

또는 말로 해도 된다.

```
[12정02-03] 성취기준에 맞게 수행평가 과제 정보표를 보고, 수행평가 문항, 채점기준표, 예시답안을 만들어줘.
```

진행 순서:

1. **정보표 확인** — 그 성취기준의 과제가 있으면 그 정보표를, 없으면 교육과정 분석 탭 내용으로 정보표를 새로 만들어 쓴다.
2. **주제 고르기** — 게임·인스타·유튜브·아이돌·연애·실생활 중 성취기준과 자연스럽게 이어지는 주제 3~4개를 추천안과 함께 보여 준다. 하나를 고른다(「기타」에 원하는 주제를 써도 된다).
3. **작성** — 문항(자료·발문·조건·배점), 채점기준표(A~E 5행), 기본점수 표, 예시답안, 정보표의 빈칸(최소 능력자 수행 특성, 수업 단계, 개발 방향)을 채운다.
4. **검사·저장** — 규칙 검사를 통과하면 앱에 넣는다. 「문항 개발」 탭에서 영역·성취기준을 고르면 바로 보이고, 「워드로 내려받기」로 연수 양식 docx 를 받을 수 있다.

개발 서버(`npm run dev`)가 켜져 있어야 한다. 꺼져 있으면 Claude 가 켠다.

## 2. 활용법

- **주제만 바꿔 다시 만들기**: 「[12정02-01] 아이돌 주제로 다시 만들어줘」 — 정보표는 그대로 두고 문항·채점기준표·예시답안만 새로 쓴다.
- **평가 방법 바꾸기**: 화면에서 평가 방법 드롭다운을 바꾸고 「새롭게 문항을 구성할까요?」에 확인 → Claude 에 「문항 초안」이라고 말하면 새 방법에 맞게 다시 구성한다(`docs/문항-초안-절차.md` 의 `redraft`).
- **영역 전체 만들기**: 「고등학교 데이터 영역 성취기준마다 만들어줘」처럼 여러 개를 요청하면 성취기준마다 주제를 묻고 차례로 만든다.
- **검사만 하기**: 손으로 고친 과제도 규칙을 지키는지 볼 수 있다.

  ```
  py -3.12 tools/item_draft.py check <과제 id>
  ```

- **동료 과제 검토는 다른 일**: 다른 선생님의 docx 양식 과제를 피드백하는 일은 이 스킬이 아니라 「수행평가 피드백.xlsx」 템플릿으로 따로 요청한다.

## 3. 생성 기준 (어디에 무엇이 적혀 있나)

| 무엇 | 기준 문서 |
|---|---|
| 칸 채우기 전체 규칙 | `docs/문항-초안-절차.md` |
| 발문·자료·조건, 반응 지시어 | 「발문과 반응지시어 정리.xlsx」 → `docs/논술형 평가/정리/소형자료.md` G절 |
| 채점기준 문장(같은 뼈대, 수식어 사다리, 「~한 경우」) | 「채점기준 예시.xlsx」 → 소형자료 F절 |
| 성취수준 어휘 위계, 최소 성취수준, 피드백 | `docs/논술형 평가/정리/00-색인.md` |
| 정보 교과 표준화 과제·채점표 예시 | `docs/논술형 평가/정리/표준화평가도구.md` |

선생님이 정한 고정 규칙:
- 채점 요소마다 **A·B·C·D·E 5행**, 등간격 정수 배점(E ≥ 2), 영역 만점 = 채점 요소별 최고점의 합.
- 기본점수는 만점의 20% 이상 40% 미만이면서 E 최저점 합보다 낮게, 장기 미인정 결석자는 기본점수 − 1점.
- 결핍어(못·미흡·부족) 금지, 수행 수준은 「~한 경우」.
- 주제는 학생 관심사와 연결하되 억지로 끼워 맞추지 않는다. 자료는 수업용 가상 자료로 표기하고 실제 회사·상표를 쓰지 않는다.

## 4. 도구 명령 (`tools/item_draft.py`)

| 명령 | 하는 일 |
|---|---|
| `find <코드>` | 성취기준의 과제 id 찾기 |
| `new <학교급> <코드>` | 교육과정 분석 내용으로 정보표를 미리 채운 새 과제 만들기 |
| `show <id>` | 과제를 `data/items/<id>.json` 으로 꺼내기 |
| `check <id 또는 json>` | 채점기준표·기본점수·배점 합·예시답안·최소 능력자 특성 검사 |
| `save <id> <json>` | 앱에 넣기(「AI 초안」 표시) |
| `pending` | 화면에서 「초안 요청」된 과제 목록 |

## 5. 처음 만든 예

- [9정04-01] 인공지능의 개념과 특성 · 인공지능 소프트웨어 구별 — **게임** 주제(가상 게임 「픽셀 아레나」 기능 카드 6장), 3문항 18점(설명 / 구별 / 두 채팅 필터 차이 설명). 과제 id 7.
- [12정02-01] 데이터 압축 — **유튜브·쇼츠** 주제(댓글 반복 글자 RLE, 영상 화질 옵션), 3문항 18점. 과제 id 3.
- 중학교 7개를 한 번에 요청한 예(주제는 성취기준마다 따로 고름, 모두 18점):
  [9정04-02] 반려동물 인스타 계정(id 8) · [9정04-03] 유튜브 댓글 감정 분류(id 9) · [9정04-04] 게임 커뮤니티 문제(id 10, 2문항) ·
  [9정04-05] 내 인스타 사진이 AI 학습에(id 11, 2문항) · [9정05-01] 유튜브 크리에이터 직업(id 12) · [9정05-02] 아이돌 팬덤 악플(id 13) ·
  [9정05-03] 유튜브 영상 만들기(id 14, 2문항).
  평가 요소가 가치·태도(예: 「~태도 갖기」)이면 채점 문항에서 빼고 자기평가·피드백으로 다룬다(id 10).
