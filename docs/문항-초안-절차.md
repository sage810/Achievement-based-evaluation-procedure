# 문항 초안 절차 (Claude Code용)

앱 「문항 개발」 탭에서 선생님이 「Claude Code 초안 요청」을 누르면 과제가 「초안 요청」 상태가 된다.
선생님이 Claude Code에 **「문항 초안」**이라고 하면 아래 순서로 양식을 채운다.
양식: 연수 「[모듈 3] 수행평가 과제 및 채점기준표 개발(양식)」 + 채점기준표 성취수준 열(연수 실습 3-2).

## 순서
1. `py -3.12 tools/item_draft.py pending` — 요청 목록.
2. `py -3.12 tools/item_draft.py show <id>` — `data/items/<id>.json` 으로 꺼내 읽는다. 이미 채워진 칸(선생님이 쓴 것, 교육과정 분석에서 온 것)은 **그대로 살리고** 빈칸을 채우거나 다듬는다.
3. 근거 자료를 읽는다:
   - `docs/논술형 평가/정리/00-색인.md` (공통 규칙·문체) → `수행평가연수_모듈3.md`(이 양식의 칸 설명), `표준화평가도구.md`(정보 과제·채점기준표 예시), `연수강의안.md`(발문·조건 템플릿)
   - 해당 성취기준의 교육과정 분석: `GET http://localhost:8000/api/analyses/<standard_id>` (평가요소 ⑦, 수준화 ⑧)
   - 영역별 성취수준: `성취수준_고등.md` / `성취수준_중학교.md`
4. 칸 채우기 규칙
   - **평가 과제명**: 보여 줄 지식·이해와 과정·기능이 드러나게 구체적으로(「~하기」).
   - **최소 능력자의 수행 특성(A~E)**: 「겨우 그 수준에 드는 학생」이 보일 수행, 「~할 수 있다.」. 성취수준 진술의 수식어 위계를 따르고 E는 최소 성취수준(성취율 40%)에서 할 수 있는 것.
   - **교육과정 분석 · 내용 요소 · 평가 요소**: 원문을 살리고, 평가 요소는 성취기준 동사 수준을 낮추지 않은 「~하기」 2~3개.
   - **평가 방법**: 논술 / 구술/발표 / 토의/토론 / 프로젝트 / 실험 / 포트폴리오 / 직접 입력(그 밖의 방법) 중 하나. 선생님이 화면 드롭다운으로 고른다.
   - **다시 구성(`redraft`)**: JSON에 `redraft`(예: 「평가 방법을 「논술」에서 「구술/발표」(으)로 바꿈」)가 있으면 선생님이 평가 방법을 바꾸고 새 구성을 요청한 것이다. 성취기준·평가 요소·교육과정 분석은 살리고, **새 `method`에 맞게** 과제명·최소 능력자 수행 특성·수업 단계·개발 방향·문항 정보·문항·채점기준표·기본점수·예시답안을 새로 쓴다(예: 구술/발표 → 발표 과제와 발표·질의응답 채점 요소, 실험 → 수업 중 실습 과정·결과물 제출). `save` 하면 `redraft` 는 자동으로 지워진다.
   - **수업 단계(lessons)**: 진단평가 → 형성평가 → 수행평가 흐름, 교사 피드백은 하위 수준/상위 수준으로 나눠 쓰고 「채점 기준의 수행 수준과 연계」「최소 성취수준 보장 연계 피드백」 포함. 수업 중 실시(과제형·암기식 ✕).
   - **개발 방향 및 활용 시 고려 사항**: 이 과제로 각 성취수준 학생이 보일 기대 수행 능력, 「~을 평가함」「~을 점검함」 개조식.
   - **문항 정보**: 문항 번호(1, 1-1 …) · 성취기준 코드 · 평가 요소 — 평가 요소 문구는 위·채점기준표와 **같은 글자**로.
   - **발문·자료·조건 규칙**(「발문과 반응지시어 정리.xlsx」, 선생님 지시 2026-10-24): 발문은 문두에 「무엇에 대해 어떻게」가 보이게 쓰고, 측정 능력에 맞는 반응 지시어(정보교과 정의: 구분·비교·설명·서술·분석·해석·평가·논증·적용·구성·제시 …)를 쓰며 [배점]을 단다. 평가 요소가 둘 이상이면 하위 문항이나 조건으로 나누어 안내한다. 조건은 내용·형식 범위를 한정하되 정답·핵심 단어를 암시하지 않고, 인정 범위가 모호하지 않게 쓴다(「자료에서 찾아 쓸 것」「사례를 구체적으로 제시할 것」). 자료는 발문과 긴밀히 연관되고 풀이 시간에 비해 과다하지 않게, 가상 자료는 출처에 표기한다. 발문의 반응 지시어와 조건은 그대로 채점기준 행에 반영한다. 주제는 학생 관심사(게임·아이돌·실생활)와 자연스럽게 연결하되 억지 연결은 하지 않는다.
   - **수행평가 문항(question)**: `※ 다음을 읽고 물음에 답하시오.` → 자료(실제 맥락, `[출처: …]`) → 하위 문항 `1. ~ <조건>에 맞게 서술하시오. [5점]` + `<조건>` `∙ ~할 것.` 반응 지시어로 측정 능력을 드러내고 조건에 정답을 암시하지 않는다. 쉬운 하위 문항 → 어려운 하위 문항.
   - **채점기준표(rubric)**: 평가 요소마다 블록, 채점 요소는 간결한 명사구. 행마다 성취수준(A, B, B-C, C-D, D-E …)·수행 수준·배점. **A~E 모두 어딘가에 나타나게**(화면 머리줄에 빠진 수준이 표시됨). 수행 수준은 「~한 경우」(마침표 없음), 수준 간 질적 차이(개수·정도·근거·논리성), 결핍형 대신 할 수 있는 것, 조건의 제한 요소 반영, 꾸미기·분량·태도로 점수를 가르지 않음. 배점은 등간격 정수.
   - **채점 요소마다 반드시 A·B·C·D·E 5행**(선생님 지시 2026-10-24): 「B-C」 같은 묶음 행, 같은 수준 2행(A 5점·A 4점) 금지. 배점은 등간격 정수(예: 6-5-4-3-2, 8-7-6-5-4, 10-8-6-4-2). 5-4-3-2-1만 쓰면 기본점수(만점의 20% 이상)가 E 최저점 합보다 낮아질 수 없으니 E가 2점 이상인 척도를 쓴다.
   - **수행 수준 쓰는 법**(선생님 지시 2026-10-24, 「채점기준 예시.xlsx」·「AI 서논술형 채점기준표 예시.xlsx」 방식): 채점 요소마다 판단 차원을 1~2가지(예: 무엇을 제시했는가 × 이유·근거의 질)로 잡고, **5행이 같은 뼈대**를 쓰되 수식어 사다리와 개수로만 수준이 갈리게 쓴다 — 정확하게·명확히·논리적으로·구체적으로(A) → 보통(B·C) → 부분적으로·일부(D·E), 모두(A) → n가지(C·D) → 하나(E). 한 행은 한두 문장, 「~한 경우」로 끝낸다(마침표 없음). 「, 또는 ~한 경우」로 여러 경우를 나열하지 않는다(위 행부터 차례로 읽어 처음 해당하는 행을 주므로 아래 행은 「~이상」·「부분적으로」로 넓게 잡으면 됨). 「1개 이상/2개 이상」처럼 바로 위 행과 겹치는 개수, 「간단히·자신의 말로」처럼 뜻이 정해지지 않은 말, 「못·미흡·부족」 같은 결핍어는 쓰지 않는다. 정답이 정해진 부분은 값(예: 절감률 70%, 암호문 VDIH)을 괄호로 밝힌다.
   - **영역 만점 = 채점 요소별 최고점의 합**. 기본점수를 더해서 만점을 맞추지 않는다(문항 [n점] 표기 합 = 영역 만점).
   - **기본점수(basic_score)**: 수행평가면 영역 만점의 20% 이상 40% 미만이면서 **E 수준 최저 점수 합보다 낮게**(구별되게).
     화면·워드에서 표로 나오도록 「항목: 내용」 줄로 쓴다: `기본점수: 4점 (영역 만점 18점의 22.2%)` / `산정 근거: …` / `참고 분할점수: A/B 18, B/C 15, C/D 12, D/E 9, E/미도달 6 (각 수준 최저 점수 합)` / `장기 미인정 결석자: (기본점수 − 1)점` / `비고: ※ …`(여러 줄 가능, 「※ 채점은 채점 요소마다 A행부터 차례로 확인하여 처음으로 해당하는 행의 점수를 부여함.」 포함).
   - **예시답안(answers)**: 문항별, 조건을 모두 충족하는 A 수준(최소 능력자) 답안.
5. `py -3.12 tools/item_draft.py save <id> data/items/<id>.json` — 요청 해제, 「AI 초안」 표시. 화면은 10초 안에 바뀐다.
6. 선생님께 무엇을 채웠는지, 확인이 필요한 부분(자료 출처·수치 등)을 짧게 알린다.

## JSON 모양 (`web/src/api.ts` 의 `ItemData`)
`area, title, standard_id, standard, levels{A..E}, min_traits{A..E}, curriculum_analysis, content{knowledge,skills,attitude}, elements, method, lessons[{stage,teaching,assessment}], dev_direction, item_info[{no,standard,element}], question, rubric[{no,element,criterion,rows[{level,text,score}]}], basic_score, answers[{no,answer}]` — 줄바꿈은 `\n`.
