## 모든 자료에 공통인 규칙
1. **순서**: 성취기준·성취수준 분석 → 지식·이해/과정·기능/가치·태도 분해 → 평가 요소(「~하기」, 2~3개, 1문항 1성취기준) → 평가 방법 → 문항(자료+발문+〈조건〉+[배점]) → 채점기준표 → 예시답안 → 채점·피드백 유의점.
2. **평가 요소 ↔ 하위 문항 ↔ 채점 요소**가 1:1로 이어지고, 개요·문항 정보·채점표에서 같은 문구로 통일.
3. **모든 성취수준(A~E) 점검**: 쉬운 하위 문항(개념·출력값) → 어려운 하위 문항(이유·비교·설계)으로 계단식. 하위 문항마다 「성취수준 ○를 고려하여 출제」 명시.
4. **난이도 목표**: 서·논술형은 목표 수준 학생의 만점 확률 약 50%, 선택형은 목표 수준 최소 능력자(MCP)의 약 2/3 정답.
5. **최소 성취수준(E, 성취율 40%)**: E 학생이 실제로 할 수 있는 문항·수행 수준 포함, **기본점수만으로 40%에 닿지 않게**.
6. **조건 = 채점기준**: 〈조건〉의 제한 요소는 모두 수행 수준에 반영, 조건에 정답 암시 금지.
7. **수행 수준**: 수준 간 질적 차이(개수·정도·근거 유무·논리성·완성도), 배타성(구간 겹침 X)·포괄성(모든 답안이 어딘가에 들어감). 생성 기준(2026-10-24 선생님 지시, 「채점기준 예시.xlsx」·AI 서논술형 예시 방식): 5행이 같은 뼈대, 수식어 사다리(정확하게·논리적으로 → 보통 → 부분적으로·일부)와 개수(모두 → 하나)로만 수준 구분, 한두 문장 「~한 경우」, 「또는」 나열 금지, 결핍어 금지, 수행평가 기본점수 표에 장기 미인정 결석자 점수(기본점수 − 1) 포함.
8. **성취수준 어휘 위계** (진술·판단·피드백 공통):
   - 지식·이해: 명확하게/정확하게/구체적으로 설명(A) → 설명(C) → 인지(D·E)
   - 과정·기능: 효율적으로/효과적으로/다양하게/오류 없이(A) → 수식어 하나 탈락(B) → 기본 수행(C) → 부분적으로/일부/주어진·제시된(D) → 일부 수행·구분·탐색(E)
   - 가치·태도: 내면화(A) → 인식(B·C) → 수용·공감(D) → 생략 또는 수용(E)
   - 상위 수준은 하위 진술에 수식어를 **더하는 누적형**, 결핍형("못한다") 대신 **할 수 있는 것**으로.
9. **실제적 맥락**: 실생활·뉴스·공공데이터·학교 상황 제시문, 출처 표기, 특정 기업 상표 피하기, 시간 대비 정보량 적당히.
10. **피드백**: 성취수준 진술 + 채점 요소별 수행 특성이 근거. 현재 수준의 「~할 수 있다」 + 한 단계 위 진술과의 차이를 다음 목표로. 잘한 점/보완할 점/다음 단계, 하위·상위 학생 이원화, 개인 칭찬 지양.
12. **발문·자료·조건**(「발문과 반응지시어 정리.xlsx」, 소형자료 G절 — 2026-10-24 선생님 지시): 발문은 문두에 「무엇을 어떻게」 + 측정 능력에 맞는 반응 지시어 + 배점. 평가 요소가 둘 이상이면 하위 문항·조건으로 나누어 안내. 조건은 범위를 한정하되 정답(핵심 단어)을 암시하지 않고, 인정 범위가 모호하지 않게(「자료에서 찾아 쓸 것」). 자료는 발문과 긴밀하고 과다하지 않게. 반응 지시어와 조건은 그대로 채점기준에 반영.
11. **수행평가 과제 정보표·채점기준표**(연수 모듈3·표준화): 성취수준별 **최소 능력자의 수행 특성(A~E)** → 채점기준표에 **성취수준 열**(A, A-B, C-D 묶음 허용)로 모든 수준 점검 → 최저 수준 점수 > 기본점수. 과제형·암기식 수행평가 금지, 부차적 과정·기능(꾸미기 등) 요구 금지.

## 자료끼리 다른 점 — 생성 전에 어느 쪽을 따를지 정할 것
| 항목 | 경기 논술형 자료(길라잡이·표준화·강의안·양식) | 교육부 성취수준 문서(중·고) | AI 채점 양식 |
|---|---|---|---|
| 수행 수준 종결 | 「~함.」 개조식 | 「~하였다.」 과거형 / 성취수준은 「~할 수 있다」 | 「~한 경우」 |
| 표 열 | 문항 \| 평가 요소 \| (채점 요소) \| 척도/배점 \| 수행 수준 | 문항(서1·수1) \| 채점 요소 \| 척도 \| 수행 특성 \| 예시 답안 | 채점기준 n \| 점수 \| 기준 |
| 최저 단계 | 0점 행 없음, 할 수 있는 내용으로(표준화: 「※ 학업 성취율 40% 미만의 수행 수준 및 배점은 생략함」) | 0점 = 무응답·전형적 오답 | 1점 「어느 것도 만족하지 않지만 유사 내용을 작성한 경우」 |
| 시작 점수 | 지필 0점에서 시작, 수행평가는 기본점수 고려 / 수행평가 채점표는 기본점수·장기 미인정 결석자 점수 칸 | — | 최소점수, 미제출·미응시 0점 |
| 예시답안 | A 수준(최소 능력자) 기준 1개 | 척도별 예시 답안 | — |
