# 2026 학생평가 전문가(기본)과정 연수 — 모듈 3 「성취수준 판별을 위한 평가도구 개발(수행평가)」

출처: (2026.10.24) 학생평가 전문가 연수 강의안 2.pdf (42쪽, 경기도교육청 중등교육과, 양평중 최명진·영북고 홍가람·안양공업고 양지현). 2026-10-24 정리.

## 1. 평가도구 개발 방향 (pp.3–8)
| 방향 | 뜻 | 실천 |
|---|---|---|
| 타당도 높은 평가도구 | 평가 과정·결과의 정보가 본래 평가 의도·목적에 부합하여 해석·활용될 수 있는 정도 | 교수·학습에서 다룬 여러 성취기준을 **균형 있게** 반영 / **상위 수준 변별보다 성취기준 도달 정도 파악** 중심 / 해당 학년 교육과정 범위를 벗어난 지식·이해, 과정·기능, 가치·태도가 없는지 확인 |
| 신뢰도 높은 평가도구 | 평가도구로부터 얻은 점수를 신뢰할 수 있는 정도 | 여러 차례 평가 결과로 종합 판단 / 출제 의도·내용을 고려해 채점기준을 명확하게 / 채점기준을 **세분화**하여 다양한 성취수준을 정확히 판별, 교사 간 **교차 검토**로 수정·보완 |
| 난이도를 고려한 평가도구 | 각 성취수준별 도달 여부를 판별하기에 적합한 난이도 | 학기 단위 성취수준 A~E 특성을 숙지해 **다양한 성취수준에 해당하는** 평가도구 개발 / 특히 **최소 성취수준에 적합한 난이도의 문항·과제를 반드시 포함** |

평가도구는 어떻게 개발하나 (p.7)
- 성취기준, 성취기준별 성취수준, 영역별 성취수준, 학기 단위 성취수준을 확인·분석해 계획 수립
- 성취기준 도달에 필요한 능력을 **평가 요소**로 구체화하고, 평가 요소를 가장 잘 평가할 **평가 방법** 선정
- 각 성취수준 도달 여부를 판별하기에 타당한 문항, **특정 성취수준에 편중되지 않고 모든 성취수준을 골고루** 평가
- 교과협의회에서 성취기준·평가 요소에 따라 정기시험·수행평가 도구 개발 계획
- 논술형·수행평가는 **수행 수준(채점기준)을 구체적으로** + **예시 답안을 함께** 개발

개발 흐름 (p.8): 성취기준 및 성취수준 분석 → 평가 요소 추출 → 평가 방법(정기시험, 수행평가) 선택 → 평가도구 개발 → 채점기준 개발 → 효과적인 평가도구

### 평가 요소 정의와 정보 예시 (p.9)
「평가 요소」란 각 과목별 성취기준 도달의 증거로, 학생들이 보여 주기를 기대하는 핵심 내용을 구체적으로 기술한 평가 내용. 평가의 목표와 특성을 고려하여 성취기준에서 도출하며, 학생의 수행 정도를 판별할 수 있도록 지식·이해, 과정·기능, 가치·태도와 같은 구체적인 내용으로 기술. 평가 요소를 고려하여 평가 방법 선정.

| 성취기준 | 평가 요소 | 평가 방법 |
|---|---|---|
| [12정02-01] 디지털 데이터 압축의 개념과 필요성을 이해하고, 압축의 효율성을 분석하여 평가한다. | 데이터 압축하기 / 압축의 효율성 분석하기 / 압축의 효율성 평가하기 | 정기시험 선택형 |
| [12정04-01] 지능 에이전트의 개념과 특성을 이해하고, 인간과 인공지능의 관계를 분석한다. | 지능 에이전트의 개념 설명하기 / 인공지능 서비스에서 지능 에이전트의 역할 탐색하기 / 바람직한 인간과 인공지능의 관계 | 정기시험 논술형 |
| [12정02-04] 빅데이터 분석 도구를 활용하여 데이터를 시각화하고 그 의미와 가치를 해석한다. | 데이터를 시각화하기 / 데이터 해석하기 | 수행평가 논술형 |
(주의: 슬라이드의 「바람직한 인간과 인공지능의 관계」는 「~하기」가 빠짐 — 생성 시에는 「~ 관계 제안하기」로 쓴다.)

### 성취수준 대표 문항의 정답 확률 (p.10)
- NAEP 「충분한 숙달(sufficient mastery)」 = 학습 내용의 약 50~80% 습득. 숙달 수준은 답을 맞힐 확률로도 해석.
- 국가수준 학업성취도 평가는 이를 근거로 문항-성취수준 연계용 숙달 수준을 마련(정구향 외, 2004; 김경희 외, 2003).
- **한국교육과정평가원 권장: 선택형은 각 수준 학생의 약 2/3가 정답, 서·논술형은 각 수준 학생이 문항별 만점을 받을 확률 50%.**

## 2. 수행평가 정의·유형·방침 (pp.11–14)
- 정의: 교과 담당교사가 교과 수업시간에 학습자들의 학습과제 수행 과정 및 결과를 직접 관찰하고, 그 관찰 결과를 전문적으로 판단하는 평가 방법(「학교생활기록 작성 및 관리지침」 별표9).
  - 학습과제: 교육과정상 교과 교육목표와 관련, 실제생활에서 의미 있고 중요하고 유용한 과제
  - 수행: 단순히 답을 선택하는 것이 아니라 스스로 답을 구성하기, 산출물·작품 만들기, 태도·가치관을 행동으로 드러내기 모두 포함
- 유형: 논술, 구술·발표, 토의·토론, 프로젝트, 실험·실습, 포트폴리오, **실기**(2026 성취평가 표준화 평가도구에 추가)

| 유형 | 방법 |
|---|---|
| 논술 | 지식·개념·원리·의견 등을 비교적 짧은 길이(한 단락 이하의 문장 형태)로 작성하거나, 자신의 주장과 근거를 완결된 글의 형태로 작성 |
| 구술·발표 | 특정 내용·주제에 대해 의견·생각을 구술·발표하게 하여 준비도, 이해력, 표현력, 판단력, 의사소통 능력 등을 직접 평가 |
| 토의·토론 | 특정 주제에 대해 서로 토의·토론하는 것을 관찰 |
| 프로젝트 | 특정 연구나 산출물 개발을 수행하게 한 뒤 전 과정과 결과물을 종합적으로 평가 |
| 실험·실습 | 직접 실험·실습하고 과정·결과 보고서를 쓰게 하여, 보고서와 교사가 관찰한 과정을 종합 평가 |
| 포트폴리오 | 학생이 산출한 자료를 체계적으로 누적 관리한 작품집 등을 대상으로 평가 |

- 방침
  - 실제 상황에서의 수행능력, 종합적·전인적, 과정과 결과 모두 중시, 전체적·지속적, 고등사고능력 측정
  - 정기시험과 수행평가로 구분하되, 학업성적관리규정으로 정해 과목 특성상 **수업활동과 연계한 수행평가만으로** 평가 가능
  - 성취기준에 기반하여 **수업시간 중** 실시. 정규교육과정 외 결과물에 점수를 주는 **과제형 수행평가 금지**, **암기식 수행평가 금지**
  - 점수화가 가능한 영역의 점수만 반영. **기본점수 부여 여부·범위는 교과별 평가 계획에 포함**, 평가 목적을 고려해 타당하게
  - 과목 고유 특성이 드러나는 다양한 활동으로 교과 역량·성장 정보 파악, 수업 상황 안에서 과정과 결과 평가
  - **2028 대입제도 개편**: 대입전형자료에 성적 외에 과목별 평가방식(정기시험/수행평가 반영 비율, **수행평가 영역명**), **학기말 성취도별 분할점수** 추가 제공
  - 성적처리 끝난 수행평가의 중요 자료는 졸업 후 1년 이상 보관

## 3. 경기도교육청 학업성적관리 시행지침 — 라. 수행평가 운영 (pp.15–20, 원문 요지)
1) 정의(위와 같음)
2) 학교장은 공정·타당한 계획과 평가(채점)기준을 마련하고 **시행 이전에 학생·학부모에게 안내**. ※ 공지된 평가 계획대로 시행(채점 포함)
3) 교과교육과정에 근거해 타당한 영역·세부기준 마련, 타당도·신뢰도 확보
4) 모든 수행평가는 수업 중 실시 원칙, 수업시간 외 가정 등에서 이루어지는 「과제형 수행평가」 금지. 사전 준비가 필요한 **암기식 수행평가도 포함**
   - 과제형: 수업 외 시간에 학교 밖에서 수행한 과제물 내용을 채점 요소로 삼아 점수 부여
   - 암기식: 생각·탐구 과정 없이 단순 기억·반복 재생산 능력만 채점 요소로 삼아 점수 부여
5) **AI 도구 활용 시 공정성·신뢰성이 훼손되지 않도록 주의, 시행 전 학생 유의사항 충분히 안내**
6) 교사별 평가 가능. 영역·요소·방법·시기·횟수·세부 기준(배점)·반영비율은 **교과협의회에서 정하고 학업성적관리위원회 심의**. ※ 영역별 비율·등급 간격 신중히
7) 일제식 정기시험으로 실시 불가, 특정 시기 집중으로 부담 과중하지 않게
8) 교육과정 재구성, 학생 참여형 수업 안에서 다양한 방법으로 **지식보다 역량**, 수행 과정과 결과 평가
9) 교과 고유 특성이 드러나는 다양한 활동으로 교과 역량·성장 정보 파악
10) 체육·예술: 실기·태도·감상·미적체험·이론·이해 반영비율 균형, 수업시간 내 활동 과정 중심
11) 전문 교과(NCS 기반): 능력단위 성취기준 근거, 편성한 능력단위별 수행평가 1회 이상
12) 정의적 능력 평가는 성취기준에서 추출한 가치·태도 요소를 수행평가에 반영할 수 있음
13) 모둠활동은 **개별 학생에게 역할 부여**, 개인별 수행 과정과 결과 평가
14) 점수화 가능한 영역만 반영, 기본점수 부여 여부·범위는 학교 학업성적관리규정으로
15) 학생·학부모 피드백 결과를 차기 수행평가 계획에 반영
16) 결시자 처리기준은 교과협의회를 거쳐 평가 계획에 반영
17) 전출 학생: 전출교는 전출일까지 결과 입력, 전입교는 입력 여부 확인
18) 결과물 보관기간은 규정으로, 확인·이의신청·성적처리 완료 후 보관
19) 성적 산출 증빙 중요 자료(학급별·교과목별 일람표 등)는 졸업 후 1년 이상 보관, 상급학교 요청 시 제공 가능

## 4. 성취수준 판별을 위한 수행평가 과제 개발 (pp.21–22)
학기 초 공지된 평가 계획에 따라 성취기준, 학기 단위 성취수준, 평가 요소, 수행평가 유형을 검토한 뒤:
- 성취기준이 수행평가로 성취수준 확인에 적합한지 검토, **성취수준과 문항 난이도를 연계해 능력의 전 범위를 평가하는 균형 있는 검사도구**로. 수행평가 과제는 **모든 성취수준을 점검**할 수 있게
- 인지적 사고 수준은 내용 체계 + Bloom(지식, 이해, 적용, 분석, 종합, 평가) / Anderson(인지과정: 기억, 이해, 적용, 분석, 평가, 창안 · 지식 차원: 사실적, 개념적, 절차적, 메타인지적 지식) 참고
- 지식·이해뿐 아니라 **과정·기능, 가치·태도 내용 요소를 포함**해 과제 개발
- 성취기준·평가 요소·인지 수준을 고려해 과제 내용과 유형(시간, 개인/집단, 구조화 정도) 결정
- **확인하려는 것과 관련성이 낮은 부차적인 과정·기능**(예: 연산문제에서 높은 읽기 이해력 요구)을 요구하지 않는지 확인, 있으면 수정
- 학생이 요구사항을 명확히 알 수 있게 **과제의 문두** 기술
- 완성에 필요한 기간·횟수·시간을 미리 공지
- 최소 성취수준 보장 지도 전략으로 형성평가에서 수행평가 과제를 활용할 때는 **E수준 학생들이 수행할 수 있는 과제**

## 5. 채점기준 개발 (pp.23–25)
- 채점기준 = 정기시험 논술형·수행평가 대상인 수행 과정이나 산출물의 질을 **구별하기 위한 실질적인 기준**. 신뢰도를 위해 명확하고 상세화. 교수·학습 과정의 학습·수행 과정과 결과가 채점 대상.
- 반영할 요소: ① 판단 준거인 구체적인 **채점 요소** ② 성취수준 준거를 평정하기 위한 **채점 요소별 척도** ③ 채점 요소에 근거해 수행 수준을 구별하는 세부적인 **수행 특성(기준)**
- 채점기준표 = 「채점 요소」 「채점 요소별 척도(점수)」 「각 척도별 수행 특성」이 제시된 진술문
- 분석적: 평가 요소별 채점·합산, 요소별 구체적 기준, 구체적 피드백 가능 / 개발·채점 시간 많이 듦

## 8. 실습 서식 — 수행평가 과제 정보표·채점기준표 (pp.34–41)
### [실습3-1] 수행평가 과제 정보표 칸 (한글 서식)
1. **과목 · 영역**
2. **성취수준별 최소 능력자의 수행 특성** — 성취기준마다 A~E 각각 「**겨우 그 수준에 드는 학생**」이 보일 수행. 모듈 5의 **분할점수**와 이어짐
3. **평가 과제명 + 성취기준 + 성취기준별 성취수준(A~E)** — 과제명은 보여 줄 지식·이해와 과정·기능이 드러나게 구체적으로, 성취수준은 원문을 옮김
4. **교육과정 분석 → 범주별 내용 요소(지식·이해 / 과정·기능 / 가치·태도) → 평가 요소**
5. **평가 방법** (□논술 □구술·발표 □토의·토론 □프로젝트 □실험·실습 □포트폴리오 □기타) → 다음 쪽에 교수·학습 활동, 진단·형성평가 연계, 개발 방향

### [실습3-2] 채점기준표 칸
- 열: **과제/문항 | 평가 요소(| 세부 평가 내용) | 성취수준 | 수행 수준(채점기준) | 배점**
- ① 평가 요소와 세부 평가 내용(나누어 볼 때)
- ② **성취수준** — 수행 수준마다 해당 성취수준(A, B, C-D처럼 **묶음 가능**)을 적어 **모든 성취수준을 점검**할 수 있게 (서식 예: A-B / C-D / E, 또는 A / B / C-D / E, A / B / C / D-E)
- ③ **수행 수준(채점기준)과 배점** — **최소 능력자의 수행 특성과 이어지게** 쓰고 수준마다 점수. **가장 낮은 수준의 점수가 기본점수와 구별되게**
- 실습 내용: 평가 요소별 수행 수준 진술, 수행 수준과 성취수준 연계, 배점과 기본점수, 예시 답안

### [실습3-3] 월드카페 모둠 간 피드백 (검토 관점)
- 검토자는 **지적이 아닌 조언자**. 개발자와 관점이 다를 수 있음을 존중하고 더 좋은 과제를 위해 피드백
- 피드백 관점 4가지 × (잘된 점 / 고칠 점·제안): ① **성취기준·성취수준 정합성**(과제가 겨냥한 성취기준·평가 요소와 성취수준 A~E 진술이 서로 맞물리는가) ② **과제 타당도·성립 여부** ③ **채점기준표** ④ 그 밖의 의견 → 개발 모둠이 반영 여부·메모
- 과제 소개 칸: 과제명, 성취기준·평가 요소, 파일 링크, 채점기준표 요점(성취수준-수행 수준-배점), 특히 의견을 듣고 싶은 점
- 최종: 〈수정 전-후 수행평가 과제와 채점 기준표 비교하기〉 서식으로 정리·공유

## 9. 생성 시 따를 점 (이 자료에서 새로 확인·강조된 것)
1. 수행평가 과제 정보표에는 **성취수준별 최소 능력자의 수행 특성(A~E 각각)**을 먼저 적는다 — 「겨우 그 수준에 드는 학생이 보일 수행」, 분할점수 산출의 근거.
2. 채점기준표에 **성취수준 열**을 두고 수행 수준마다 A~E(묶음 허용)를 병기, 모든 수준이 어딘가에 나타나게.
3. 수행 수준 진술은 최소 능력자 수행 특성과 이어지게, 학기 단위 성취수준 특성이 반영되게, 수준 간 질적 차이가 분명하게.
4. **최저 수준 점수 > 기본점수** (구별되게).
5. 과제는 수업 중 실시 가능한 것만(과제형·암기식 금지), 부차적 과정·기능(꾸미기, 과도한 읽기 부담 등)을 요구하지 않게, 문두에 요구사항을 명확히.
6. 모둠 과제는 개별 역할·개인별 과정과 결과를 평가하도록 설계. AI 도구 활용 과제는 공정성·신뢰성 유의사항 안내 문구 포함.
7. 과제명은 지식·이해와 과정·기능이 드러나게 구체적으로(예: 「빅데이터 시각화를 활용한 사회문제 해결 방안 찾기」).
8. 검토·피드백 글은 지적이 아니라 조언 어조, 4관점(성취기준·성취수준 정합성 / 과제 타당도·성립 / 채점기준표 / 기타)으로 잘된 점과 고칠 점·제안을 나눠 쓴다.
