## A. 논술형 평가 문항 개발 양식(00중고_000).hwp — 양식 + 작성 지침(메모)

### 양식 구조 (자료집 양식과 같음)
1. **평가 개요**: 학교급 · 학년 · 과목명 · 영역 · 평가 방법(수행평가 / 지필평가) · 평가 시간(예상) · 성취기준별 성취수준(코드 → 줄바꿈 → 진술문, A~E) · 평가 요소 · 논술형 평가 제작 의도(출제 의도)
2. **수업 계획 및 흐름도**: 차시별 수업 흐름(개발 문항 차시는 진하게) · 평가 방법(진단평가 / 수행평가(논술형) …) · 수업-평가 연계 주안점
3. **평가 문항**: 문항 정보(문항 | 교과 역량 | 성취기준 | 평가 요소) · 평가 문항 · 채점기준표(문항 | 채점 요소 | 배점 | 수행 수준(채점기준)) · 채점 시 유의점 · 예시 답안 · 피드백 시 유의점

예시 문항 형식: `※ 다음 글을 읽고 물음에 답하시오. [총 20점]` → 자료 (가)(나) + 출처 `《매체》 날짜 자` → `1. (가)와 (나)를 토대로 ~을 분석하시오. [5점]` `2. ~을 선정하고, ~한 이유를 설명하시오. [15점]`
채점기준표는 문항 → 평가 요소 → 하위 채점 요소(예: 「공간의 성격 분석」 3점, 「상징성과 주제의식 연결」 4점)로 쪼개고 배점마다 한 줄.

### 작성 지침 (양식 메모, 그대로)
- 수행과제: 구체적으로, **「~~하기」로 통일**, 지나치게 포괄적인 제목 지양
- 출처 표기 통일 (교과별 마지막 페이지에 참고문헌 정리), **특정 기업의 상표 피하기**
- 글꼴: 제목 맑은 고딕 18pt · 표 10pt · 본문 11pt. 가운데점은 유니코드 00B7(·), 글머리 기호 ∙ 는 2219 + 한 칸 띄우기
- 성취기준: 코드 다음 줄바꿈 후 진술문, 양쪽 정렬
- 출제 의도: **성취기준과 성취수준을 고려한 설계 의도를 먼저**, 문항 제작 시 고려한 성취수준 설명 포함 (특정 수준만 타겟하지 않는 경우도 있음)
- 수업-평가 연계 주안점: 학생이 논술형 평가를 해결할 때 **특히 관심을 가져야 할 사항** 중심
- 평가 요소는 1쪽(개요)과 4쪽(채점기준표)에서 **통일**
- 채점기준표: 문항·평가 요소·채점 요소·배점은 가운데 정렬, 수행 수준은 양쪽 정렬. **3~5수준 권장**
- 수행 수준 검토: 성취기준·성취수준과 수행과제의 연계성 확인 / **성취기준 및 학기 단위 성취수준과 무관한 기준은 없는지** 확인
- **지필평가는 0점에서 시작, 수행평가는 기본점수 고려**
- 수행 수준은 **「~~함.」 개조식** 진술. 교과에 맞게 재구성
- 예시 답안을 쓰면서 수행 수준을 다시 검토 (평가 요소별 성취기준·성취수준 연계성), 예시 답안도 「~~함」 개조식 가능
- 채점 시 유의점 예: 「채점기준의 구체적 요소들이 모두 충족되었으며 그 의미가 명확하게 표현되어 있는지를 고려하여 평가해야 함.」「채점기준을 충족함을 전제로 예시 답안에서 제시한 내용 외에 객관적으로 인정할 수 있는 내용을 작성하였을 시에 감점 요인으로 판단하지 않아야 함.」
- 피드백 시 유의점 예: 「해당 교과의 성취기준을 확인하고, 내용과 문항의 난이도, 성취수준 부합 정도를 고려하여 피드백함.」「지문의 중요 내용을 분석하여 해당 요소 간의 연관성을 추론할 수 있는지를 확인하여 피드백함.」
- 출제 의도 예: 「본 문항은 ~ 맥락에 근거하여 ~ 글을 쓸 수 있도록 설계하였다.」「특히 최소 능력의 판별을 위하여 ~에 대해 우선 교사의 안내를 제공하도록 한다.」

## B. 논술형 채점기준표 예시.pdf (『2026학년도 중등 학생평가 및 학업성적관리 이해하기』 pp.62–65)
수행평가 채점기준표 양식: **평가 영역명 · 영역 만점 · 학기 · 수행과제(∙ 여러 줄) · 성취기준 + 성취기준별 성취수준 · 평가 방법(□논술 □구술·발표 □토의·토론 □프로젝트 □실험·실습 □포트폴리오 □기타 / □교사 관찰 및 기록 □자기평가 □동료평가) · 평가 요소(배점) | 수행 수준(채점기준) | 배점 · 기본점수 · 장기 미인정 결석자 점수**

예시 4개: 중 기술·가정 [9기가02-09] 주거 공간(20점, 기본 5, 장기결석 4) / 중 미술 [9미02-01·03] 인포그래픽(25점, 3수준 성취수준, 기본 7·6) / 고 통합과학 [10통과1-01-04] 디지털 정보 처리 기술 활용 방안 고안하기(20점, 기본 6·5) / 고 통합사회 [10통사2-01-03] 인권 문제 해결 프로젝트(20점, 기본 5·4)

수행 수준 문장 패턴 (모두 「~함」 체):
- **개수 사다리**: 「(구성 방안: 구역화, 동선, 공간 활용 방식)을 **모두** 활용하여 ~함 4 / 중 **두 가지만** ~ 3 / 중 **한 가지만** ~ 2」 — 괄호 안에 판단 요소를 명시
- **정확성 사다리**: 「~ 구분하여 정확하게 설명함 4 / ~ 구분하여 일부만 정확하게 설명함 3 / ~ 구분하지 않고 일부만 설명함 2」
- **최저 단계 = 참여**: 「~하는 활동에 참여함 1」(수행평가 특유)
- **완성도**: 「~을 모두 활용하여 … 완성도 있게 구성함 8 / 모두 활용하여 구성함 **또는** 일부를 활용하였지만 완성도 있게 구성함 6 / 일부를 활용하여 구성함 4 / 참여함 2」 — 한 배점에 두 경우(또는)
- **측면 수**: 「원인을 다양한(정치, 사회, 문화 등) 측면에서 타당하게 분석함 4 / 2가지 측면 3 / 1가지 측면 2」
- **질적 단계**: 「참신한 발상으로 적합한 표현 효과를 적용하여 체계적으로 계획함 9 / 적합한 발상과 표현 효과를 적용하여 계획함 6 / 발상과 표현 효과를 계획함 3」
- 평가 요소 → 하위 채점 요소로 쪼개기 (예: 「이산화 탄소 농도 측정하기(5점)」 = 「신호 측정하기」 3 + 「신호 정의하기」 2)
- 고 통합과학 예: 「정보 통신 기술(아날로그 신호의 특징, 디지털 신호의 특징, 신호의 종류, 센서의 역할)을 모두 정확하게 분석함 5 / 중 3가지만 4 / 2가지만 3 / 1가지만 2 / 기술을 설명함 1」

## C. AI 서논술형 채점기준표 예시.xlsx (AI 채점 도구 입력 양식)
구조: 1. 기본 정보(성취기준, 평가명) → 2. 성취기준(A~E) → 3. 채점기준(채점기준 n = 평가 요소, 5.0~1.0점 줄마다 「~한 경우」) → 4. 점수(영역만점 15.0, 최소점수 3.0) → 5. 결시자 처리(미제출 0.0, 미응시 0.0)
예: [9정04-04] 「인공지능 활용 분석나누기」
- 채점기준 1 인공지능 시스템 적용 원리 설명하기: 5 「지문 내용을 근거로, 적용 원리를 이용하여 환경 보호를 위한 역할을 2가지 모두 제시한 경우」 / 4 1가지만 / 3 원리 없이 역할 1가지 / 2 지문 근거 없이 역할 제시 / 1 「평가 요소의 내용 중 어느 것도 만족하지 않지만 유사 내용을 작성한 경우」
- 채점기준 2 인공지능으로 해결 가능한 문제 발견하기: 「지문에 없는 … 환경 문제 1가지 + 사용 이유를 구체적이고 논리적으로」5 / 구체적으로 4 / 간략히 3 / 문제만 2 / 유사 1
- 채점기준 3 인공지능 활용의 효과와 한계 분석하기: 긍정·부정 각 1가지 + 이유 각각 논리적으로 5 / 간략히 4 / 1가지 영향만 이유와 3 / 영향만 각각 2 / 유사 1
- 문체: AI 채점용은 「~한 경우」로 끝남. 조건 충족 개수·근거 유무·이유의 구체성(논리적 > 구체적 > 간략히 > 없음)으로 단계화.
- 주의: 이 예시의 D·E 성취수준 문장은 다른 성취기준([9정04-05] 윤리 문제)의 것이 섞여 있음 → 생성 시 성취수준 문장은 반드시 DB의 해당 성취기준 것을 쓴다.

| 예측하시오 | 주어진 데이터나 정보 기술의 변화, 프로그램 실행 결과, 디지털 사회 현상 등을 근거를 바탕으로 예상하는 것 |
| 추론하시오 | 주어진 자료나 프로그램 결과, 데이터 패턴 등을 바탕으로 논리적인 결론이나 원인을 도출하는 것 |
| 평가하시오 | 정보 기술, 프로그램, 알고리즘, 디지털 윤리 사례 등의 장점·한계·효율성·적절성을 기준에 따라 판단하는 것 |
| 적용하시오 | 정보 개념, 프로그래밍 원리, 알고리즘, 자료 처리 방법 등을 새로운 문제 상황 해결에 활용하는 것 |
| 구성하시오 | 알고리즘, 순서도, 프로그램, 데이터 구조, 정보 표현 방식 등을 목적에 맞게 체계적으로 설계하거나 만들어내는 것 |
| 비평하시오 | 정보 기술이나 디지털 사회 현상, 인공지능 활용 사례 등에 대해 비판적 관점에서 타당성과 영향 등을 논의하는 것 |
| 논증하시오 | 자신의 주장이나 해결 방법이 타당함을 정보, 자료, 근거, 논리적 이유 등을 활용하여 설명하는 것 |
| 서술하시오 | 정보 처리 과정, 프로그램 동작 원리, 문제 해결 과정 등을 순서에 따라 자세하게 기술하는 것 |
| 해석하시오 | 데이터, 그래프, 프로그램 실행 결과, 디지털 현상 등의 의미를 이해하고 이를 설명하거나 결론을 도출하는 것 |
(엑셀에는 「2026 중등 학생평가 및 학업성적관리 이해하기」 정의, 표준국어대사전 뜻, IB 용어(Explain, Analyse, Evaluate, Justify …)도 함께 있음. 「설명하시오」의 2026 정의는 「구체적인 사례를 들어 용어를 정의하는 능력」, 「서술하시오」는 「사건이나 생각 따위를 차례대로 말하거나 쓰는 능력」.)

## E. 논술형 채점기준표 피드백 표.xlsx — 동료 문항분석하기 (O/△/X + 수정방향)
| 분석 항목 | 점검 질문 |
|---|---|
| 전체 설계 | 실제적 맥락에 기반한 평가인가? / 다양한 관점을 여는 평가인가? |
| 문항/성취기준 | 채점기준표에 제시된 성취기준에 부합하도록 구성되었는가? |
| 발문/반응지시어 | 무엇에 대해 어떻게 응답해야 하는지 명료하게 작성되었는가? |
| 자료 | 문제해결 시간을 고려했을 때 적당한 양의 정보를 포함하고 있는가? |
| 채점기준 | 평가하고자 하는 목표와 내용을 충분히 반영하는가? / 포괄성과 배타성을 갖추었는가? / 수행 과정과 결과에 피드백을 줄 수 있을 만큼 명료한가? / 채점자가 바뀌어도 일관된 점수를 줄 수 있는가? |
| 예시답안 | 채점기준표에 따라 예시답안을 검토 — 예시답안의 적절성 |
| 제시문 수준 | 평가 문항과 평가 대상의 수준에 비추어 적절한가? |
| 종합 | 전체적으로 수정 또는 보완하면 좋을 점 |

## F. 채점기준 예시.xlsx (정보과 채점기준 4예시, 2026-10-24 선생님 제공 — 채점기준 문체의 기준)
채점기준(=채점 요소) 4개, 각 5~1점 5행. **행 5개가 같은 뼈대**를 쓰고 수식어·개수만 달라진다.
- 알고리즘 작성하기: 「입력, 처리, 출력의 단계별 알고리즘을 작성하고 데이터의 흐름을 서술함 + 조건문·반복문 포함, 기준을 정확하게 설계함」(5) → 흐름을 **부분적으로** 서술(4) → 작성하였으나 흐름·제어문을 부분적으로 서술(3) → 알고리즘을 **부분적으로** 작성, 흐름과 제어문 중 **일부** 포함(2) → 부분적으로 작성, 일부 반영(1)
- 프로그램 구현하기: 입력·처리·출력 **정확하게** + 조건문과 반복문 적절히 + **오류 없이**(5) → 입력과 출력 정확 + 조건문 **또는** 반복문 오류 없이(4) → 입력 **또는** 출력 정확 + 제어문 **부분적으로 오류**(3) → 입력 또는 출력 부분적으로 + 부분적으로 오류(2) → 전반적인 오류·명령어 누락(1)
- 기계학습 유형과 이유: 「유형(회귀·분류·군집) 중 하나를 제시하고 그 이유를 ___ 서술함」 — 논리적이고 구체적으로(5) → 논리적으로(4) → 타당하게(3) → 부분적으로 타당하게(2) → 이유 없이 제시(1)
- 정보보안 기술과 디지털 윤리: 개념을 **명확히** + 실천 방법 **구체적으로 모두**(5) → 개념 + 실천 부분적으로(4) → 개념 **일부** + 실천 부분적으로(3) → 개념 일부(2) → 개념 미흡(1) — 끝맺음 「~한 경우」(나머지 셋은 「~함.」)
- 적용: 한 행 한두 문장, 「또는」로 경우 나열 ✕, 판단 차원 1~2개, 위 행부터 읽어 처음 해당하는 행. 결핍어(미흡)는 원문에 있으나 우리 생성물에는 쓰지 않음(길라잡이 규칙 우선).

## G. 발문과 반응지시어 정리.xlsx (2026-10-24 선생님 지시: 문항 글을 만들 때 반드시 따름)
### 문항 구성 요소별 제시 방법·유의 사항
| 요소 | 지침 |
|---|---|
| 발문 | **문두**에 두어 학생이 「무엇에 대해 어떻게 응답해야 하는지」 분명히 알게 쓴다. 측정하려는 능력이 드러나는 **반응 지시어**를 쓴다. |
| 보기·자료 | 문제 상황을 분명히 파악하고 답안 작성에 도움이 되게 제시한다. 자료와 발문이 긴밀히 연관되게, 신뢰성·정확성에 유의한다(가상 자료는 표기). 문제 해결 시간을 고려해 **과다한 정보를 넣지 않는다**. |
| 조건 | 학생이 반응할 내용·형식의 범위를 적절히 한정한다. **정답 전체·일부를 암시하지 않는다.** 정답 인정 범위가 모호하지 않게 필요한 사항을 넣는다(예: 「자료에서 찾아 쓸 것」, 「사례를 구체적으로 제시할 것」). |
| 문항 구성 | 유형·성격에 따라 발문만으로, 또는 자료·조건·보기를 더해 구성한다. **발문의 반응 지시어와 조건은 수행 수준(채점기준)에 반영**한다. 발문과 조건에 학생이 써야 할 내용을 명확히 제시한다. |
| 반응 지시어 | 답을 어떻게 써야 하는지 지시하는 동사. 교과 내용 체계의 「과정·기능」에서 찾아 구체화할 수 있다. |

### 바람직한 발문 / 지양해야 할 발문
- 바람직: 평가 요소를 명확히 표현 · 명확한 반응 지시어 · **평가 요소가 둘 이상이면 구분하여 안내**(하위 문항·조건으로 나눔) · **배점 표시**로 답안의 중요도 안내
- 지양: 정답에 들어갈 핵심 단어를 발문에 미리 제시 · 모호하거나 중의적인 표현 · 평가 요소를 불명확하게 표현 · 여러 요소를 구분 없이 뭉뚱그림 · 배점이나 답안 작성 방향 안내가 없음

### [정보 교과] 반응 지시어 18개 — 정보교과 정의 (D절 표와 같음, 이 파일에는 「2026 중등 학생평가 이해하기」 정의·표준국어대사전·IB 열이 함께 있음)
발문의 동사는 측정 능력에 맞춰 고른다: 구분(차이점 기준으로 나누어 설명) / 분류(공통 특성·기준으로 유형별로 나눔) / 비교(공통점과 차이점 함께) / 대조(차이점 중심) / 설명(원인·과정·결과를 포함해 구체적으로) / 서술(과정·원리를 순서대로 자세히) / 요약 / 분석(구성 요소별로 나누어 구조·관계·문제점·특징 파악) / 해석(데이터·그래프·실행 결과의 의미를 이해해 설명·결론) / 예측(근거를 바탕으로 예상) / 추론(자료·결과·패턴에서 논리적 결론·원인 도출) / 평가(장점·한계·효율성·적절성을 기준에 따라 판단) / 비평(비판적 관점에서 타당성·영향 논의) / 논증(주장·해결 방법의 타당함을 근거로 설명) / 적용(개념·원리·알고리즘을 새 문제 상황에 활용) / 구성(알고리즘·프로그램·데이터 구조·표현 방식을 목적에 맞게 설계) / 제시(판단·해결 방법·결과를 간단명료하게 나타냄)
- 2026 정의 중 유의: 「설명하시오」= 구체적인 사례를 들어 용어를 정의하는 능력, 「서술하시오」= 차례대로 쓰는 능력, 「제시하시오」= 주장·결과에 대한 자신의 판단 제시, 「평가하시오」= 상대적 중요성을 평가·판단, 「해석하시오」= 지식으로 정보의 흐름을 파악하고 결론.
