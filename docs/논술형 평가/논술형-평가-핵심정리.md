## 1. 기본 개념

| 용어 | 뜻 |
|---|---|
| 논술형 평가 | 지식의 심층적 이해·탐구, 분석·판단 등 사고 과정을 **학생 자신의 언어로 논리적으로 기술**하게 하는 평가 |
| 목적 | 분석적 이해력, 비판적 사고력, 창의적 문제해결력 등 고등 사고력 중심의 학습경험 |
| 성취기준 | 영역별 내용 요소(지식·이해, 과정·기능, 가치·태도)를 학습한 결과 할 수 있기를 기대하는 도달점 |
| 성취수준 | 성취기준 도달 정도. 성취기준별(3~5수준) / 영역별 / 학기 단위(A~E 또는 A~C) |
| 평가 요소 | 성취기준 도달의 **증거**로 학생이 보여 주기를 기대하는 핵심 내용. 성취기준·성취수준 분석으로 도출, **명사형 「-하기」**로 진술 |
| 수행 수준(채점기준) | 응답이 어느 척도에 해당하는지 판단하는 기준. 수준별로 **질적 차이**가 드러나게 진술 |
| 최소 능력의 수행 특성 | (고등학교만) 성취율 40%에 도달한 학생이 수행할 수 있는 특성. E에 가까스로 도달한 수준 |

### 논술형 유형 (경기도교육청)
| 구분 | 제한형 논술 | 확장형 논술 |
|---|---|---|
| 응답 길이 | 한 문장 이상 | 한 문단 이상 |
| 응답 양식 | 분량·내용 범위·서술 양식 제한 | 응답의 자유도 허용 (확장형도 분량·범위 제한 가능) |
| 요구 | 서술의 깊이·넓이·정확성 | 의견·주장의 완결성, 완성도, 논리적 글쓰기 |

평가 유형 표기: **지필평가 논술형** / **수행평가 논술형**

### 경기도 논술형 평가 방향 5가지
1. 미래역량을 함양하는 논술형 평가 2. 깊이있는 수업과 연계한 논술형 평가 3. 성취기준에 근거한 논술형 평가
4. 수행 수준(채점기준)이 명확한 논술형 평가 5. 피드백과 성찰을 일으키는 논술형 평가

- 단순 기억으로 답할 수 있는 내용을 묻는 것은 **지양**. Anderson 인지 과정의 상위 수준(분석·평가·창조)을 겨냥.
- 김영정 고등 사고력 7범주: 기호적·분석적·추론적·종합적·대안적·발산적·상징적 사고 (논리적 사고 ↔ 창의적 사고)

### 범주별 평가 방법
- 지식·이해: 논술·구술로 인지적 차원 평가 (배운 지식으로 주변 현상을 설명하게)
- 과정·기능: 수행 과정 관찰 + 논술형 문항으로도 구성
- 가치·태도: 체크리스트 관찰, 성찰 일지, 자기 점검표 (논술형에서는 「관계 제안하기」「견해 밝히기」 같은 문항으로 평가)

## 2. 문항 제작 절차
1. **성취기준·성취수준 분석**: 성취기준, 성취기준별·영역별·학기 단위 성취수준 확인 → 지식·이해 / 과정·기능 / 가치·태도 확인
   (가치·태도는 성취기준 문면에 없어도 성취수준·해설·고려 사항에서 도출 가능)
2. **평가 요소 도출**: 「~하기」 명사형. 예) 지능 에이전트의 개념 설명하기 / 인공지능 서비스에서 지능 에이전트의 역할 탐색하기 / 바람직한 인간과 인공지능의 관계 제안하기
3. **평가 방법 선택**: 논술형 평가(지필평가) / 논술형 평가(수행평가)
4. **문항 구성 요소 조합**: 발문(직접/간접) + 보기·자료 + 조건
5. 채점기준표 → 예시답안 → 채점·피드백 시 유의점

### 문항 구성 요소
| 요소 | 작성 원칙 |
|---|---|
| 발문 | 문두에. 학생이 **무엇**에 대해 **어떻게** 답할지 분명하게. 측정 능력이 드러나는 **반응 지시어** 사용. 끝에 배점 `[n점]` |
| 보기·자료 | 문제 상황을 분명히, 발문과 긴밀히 연관, 신뢰성·정확성, 정보량 과다 금지, 출처 표기 `[출처: … 재구성]` |
| 조건 | `<조건>` 아래 `∙ ~할 것`. 내용·형식 범위 한정, **정답(일부)을 암시하지 않기**, 인정 범위가 모호하지 않게 |

문항 형식 예: `1 다음 글을 읽고 물음에 답하시오. [총 20점]` → `1-1. … 서술하시오. [5점]` 하위 문항. 답란 틀 제시 가능 (`(1) 문제 상황:` `(2) 지능 에이전트 역할:`, 표 형식 「문제점 1 / 문제점 1에 대한 해결방안」).

### 반응 지시어
| 지시어 | 의미 |
|---|---|
| 요약하시오 | 중심 생각을 체계적으로 정리 |
| 분류하시오 | 유사 특성 대상을 유목화 (하위→상위로 묶기) |
| 구분하시오 | 유형에 따라 나누기 (상위→하위로 나누기) |
| 비교하시오 | 공통점(유사점)과 차이점 진술 |
| 대조하시오 | 차이점을 강조해 진술 |
| 제시하시오 | 주장·결과에 대한 자신의 판단 제시 |
| 묘사하시오 | 핵심 특징 서술 |
| 설명하시오 | 구체적 사례를 들어 용어 정의 |
| 분석하시오 | 구성요소로 나눠 각 의미와 관계를 말함 |
| 예측하시오 | 미리 헤아려 짐작 |
| 추론하시오 | 알고 있는 정보로부터 논리적 결론 도출 |
| 평가하시오 | 발상·의견의 상대적 중요성 판단 |
| 적용하시오 | 문제 상황에 지식·원리 사용 |
| 구성하시오 | 논리적 형식·도식으로 정보 나타내기 |
| 비평하시오 | 작품·주장에 비판적 견해 제시 |
| 논증하시오 | 주장에 이유와 근거를 들어 설명 |
| 서술하시오 | 상황을 상세하게 글·그림으로 설명 |
| 해석하시오 | 정보의 흐름을 파악하고 결론 내리기 |

Anderson 수준별 동사(참고): 기억(정의·나열·확인) < 이해(설명·요약·비교·분류) < 적용(계산·예측·문제해결) < 분석(분석·연결·조직·유추) < 평가(평가·판단·비판·논박·정당화) < 창조(설계·개발·구성·제안·가설)

## 3. 성취수준과 문항 난이도 연결
- 성취평가는 **모든 성취수준을 고르게 점검**할 수 있어야 함.
- **수준별 대표 문항은 그 수준 학생이 만점 받을 확률 50%**가 되도록 설계.
- 출제 의도에 「본 문항은 성취수준 ○를 고려하여 출제한 것으로 …」라고 하위 문항마다 대상 수준을 밝힘.
  - 정보 예: 1-1 개념 서술 → **E**(지식·이해, 최소 능력 확인) / 1-2 역할 탐색·적용 → **B·C** / 1-3 영향 추론·인간 역할 제안 → **C**(가치·태도)
  - 데이터 예: 1-1 시각화 해석 → **C** / 1-2 수집 데이터·긍정 영향 → **D**(최소 능력) / 1-3 문제점·해결 방안 → **A**
- 최소 능력 문항: E 수준 학생이 수행할 수 있게, 성취율 40% 점수와 연결. **기본 점수만으로 40%에 도달하지 않게** 할 것.
- 성취수준(5단계)과 채점 척도가 1:1일 필요 없음 (척도 3~6개 적당).

### 성취수준 일반 특성 (5수준)
| 수준 | 성취율 | 특성 요약 |
|---|---|---|
| A | 90% 이상 | 매우 우수. 이해 깊고 전이 매우 높음, 다양·복잡한 맥락 적용, 가치·태도 내면화·적용 범위 매우 넓음 |
| B | 80~90% | 우수. 다양한 맥락 적용, 기능 능숙한 편, 가치·태도 조직화 |
| C | 70~80% | 보통. 일부 맥락 적용, 기능 중간 수준, 가치·태도 일부 조직화 |
| D | 60~70% | 다소 제한. 낮은 위계 개념 이해, 제한된 맥락 적용, 기능 기본 부분 수행, 가치·태도 의미 앎 |
| E | 40~60% | 제한. 낮은 위계 개념 일부 이해, 기능 일부 수행, 가치·태도 일부 의미 앎 |
(3수준: A 80% 이상 / B 60~80% / C 40~60%)

## 4. 채점기준표
구성: **문항 | 평가 요소 | 척도/배점 | 수행 수준(채점기준)** + 채점 시 유의점 + 예시답안 + 피드백 시 유의점

- 평가 요소: 성취기준 바탕, 문항에 맞게 구체화. 하위 평가 요소로 쪼갤 수 있음
  (예: 1-2 「역할 탐색하기」 = 「문제 상황 서술하기」 3점 + 「지능 에이전트의 역할 탐색하기」 6점)
- 척도: 점수, 상/중/하, A~E, P/F
- **조건의 제한 요소는 채점기준에 반드시 포함** (공정성)
- 진술 방식 2가지: 「평가 요소별 척도별 수행 특성 진술」(성취수준 준거) / 「문항 중요도에 따른 배점별 특성 진술」(현장식 — 조건의 요구를 배점별로, 양적·질적 차이)
- 같은 배점에 두 경우를 함께 둘 수 있음 (예: 3점 = 핵심어 모두 포함했으나 일부 오류 **또는** 핵심어 일부 빠졌으나 개념은 옳음)
- 최저점은 보통 「~하지 않음」에 기본 점수 부여 (예: 1점 「개념을 설명하지 않음」)

### 수행 수준 진술 패턴 (정보 예시에서)
- 개수 사다리: 「목표, 인식, 학습, 추론, 행동 **모든** 요소 / **4가지** / **3가지** / **2가지** / **1가지 이하**가 구체적으로 드러나도록 서술함」
- 질 사다리: 「구체적으로 제시함 / 구체적이지 않게 제시함 / 제시하지 않음」
- 논리 사다리: 「논리적으로 추론함 / 추론하였으나 논리성이 다소 부족함 / 논리적으로 추론하지 않음」
- 정확성 사다리: 「명확하게 제시하고 근거를 구체적으로 제시함 / … 일부 오류가 있음 / 근거는 제시하지 않음 / 제시하지 않음」
- 문장 끝은 「~함」「~음」 체. 학생의 가치를 판단하는 표현 금지.

### 유형
- 일반적(여러 과제 공용) vs 과업 특수적(한 과제 전용, 채점 쉽고 일치도 높지만 사전 공개 어려움)
- 분석적(기준별 점수 합산, 진단·피드백에 유리, 시간 많이 듦) vs 총체적(전체 인상으로 한 수준, 빠르지만 일관성 어려움)

### 검토 기준
타당성(평가 요소가 성취기준 기반인가) · 배점(요소 중요도 반영, 급간 명료) · **배타성**(수준 간 명확히 구분) / **포괄성**(평가할 능력을 빠짐없이) · 명확성(누가 채점해도 같은 결과) · 실용성 · 문항 기술(어휘 적합, 편파 없음, 맞춤법)

### 채점 시 유의점 쓰는 법 (예)
- 「핵심 개념(…)을 명확히 인식한 후 실제 문제 해결 상황에 올바르게 적용하여 서술하였는지 확인해야 함.」
- 「E 수준의 경우에는 단편적인 수준, 지문에 있는 내용을 그대로 제시하는 수준에서 이루어질 것으로 예상함.」
- 「하위 수준으로 갈수록 탐색의 적극성, 구체적 표현 및 체계적 분석, 근거의 풍부성과 타당성의 수준이 낮아지는 것을 고려해야 함.」
- 「기존에 학습한 내용을 새로운 문제 상황에 적용하여 문제를 해결하는 능력을 평가함.」
- 채점 신뢰도: 채점자 간(가채점 후 비교) / 채점자 내(일관성, 후광 효과·피로 주의)

### 문항 체크리스트 (자기 점검 8문항)
성취기준 부합 · 지식·이해/과정·기능/가치·태도 종합 · 다양한 상황·맥락 적용 · 고차 사고 측정 · 채점기준이 출제 의도 반영 · 수준 변별 · 피드백 가능할 만큼 명료 · 채점자가 바뀌어도 일관

## 5. 피드백
- 목표 참조 피드백(목표 성취 과정·정도) / 자기 참조 피드백(이전 수행 대비 향상)
- 결과뿐 아니라 **과정**에 대해서도, 실패보다 진보·성취 강조, 교사·동료·자기 평가 활용
- 피드백 시 유의점 쓰는 법 (예)
  - 「개념을 『주어진 일을 자동으로 수행하는 인공지능이다』처럼 포괄적으로 서술한 학생에게는 목표를 명확히 하고, 환경 정보·학습·추론 같은 지능적 행동을 구체화하도록 피드백한다.」 — **흔한 부족한 답 → 무엇을 보완하게 할지** 형식
  - 「영향을 서술할 때 영화·책의 상상이 아닌지, 기술적으로 실현 가능한지 스스로 검토하도록 한다.」
  - 「느린 학습자에게는 비계를 설정하여 단계별로 성취하도록, 우수한 학습자에게는 사고 확장을 위한 조언적 피드백」
  - 「평소 수업 시간에 학생을 관찰한 내용을 고려하여 피드백한다.」
